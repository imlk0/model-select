排序、价格和填写字段怎么读？

每个字段只在相应候选范围内比较。能力分为已收录 Coding 与 Agentic 指标的均值，要求两项都有数据且量纲一致；速度按输出 tok/s 降序；性价比为能力分 ÷（10,000 输入 + 2,000 输出 token 的成本）。此成本只用于统一比较，不是实际任务账单。缺少指标的模型作为未排序候选补足展示，不标名次；同值并列。
